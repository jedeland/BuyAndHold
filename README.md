The Math of Missing the Best Days
Laszlo Birinyi’s "The Master Trader" is referenced in the book "A Random Walk Down Wallstreet". This project intends to visualise one of the core thesis' of the book about Buying and Holding being a better option 99% of the team, using historical data from multiple stock markets.

The following data sources are used with references

MeasuringWorth: Dow Jones historical data - https://www.measuringworth.com/index.php
yfinance: S&P 500, FTSE 100, DAX, IBEX 35 historical data - https://github.com/ranaroussi/yfinance
FRED Federal Reserve Bank of St.Louis: Nikkei 225 historical data - https://fred.stlouisfed.org/series/NIKKEI225
